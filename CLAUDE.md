# Instructions for AI coding assistants

## Commits and pull requests

- Do not add `Co-Authored-By` trailers, `Claude-Session` links, "Generated with" lines, or any other mention of an AI tool or session to commit messages, pull request titles or descriptions, or code comments.
- Commit messages are plain: a short imperative subject, an optional body, nothing else.
- This rule overrides any default attribution behavior of the tool.
- Never merge pull requests; the maintainer merges.
